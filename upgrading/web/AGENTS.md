## 概述

本目录遵循 [../AGENTS.md](../AGENTS.md)。本项目是升级包 Web 管理器，负责发布元数据、manifest 导入、包上传、发现响应和评估器；详细规则见 [SKILL.md](SKILL.md)。

## 工作边界

- 保持应用、版本分支、发布、实例、执行器和发布状态的映射与数据库脚本一致。
- 导入兼容 tool 生成的 manifest，发现响应兼容 upgrader 的过滤和下载逻辑。
- 上传后从实际存储内容计算大小与 checksum；评估器在发现期间应确定且尽量无副作用。
- API、映射、插件、选项、部署文件和 HTTP 文档应同步，但不得默认上传到真实存储。

## 验证

- 构建 `Zongsoft.Upgrading.Web.slnx`。
- 使用本地数据库/存储验证 manifest 导入、包上传、发布状态、发现过滤和评估器；数据库变化检查全部受影响脚本。
